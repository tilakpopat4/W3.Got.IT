Detection & Fusion Rules

Fused Confidence Formula

Confidence = 0.7 × P(XGBoost) + 0.3 × [1 - exp(-Anomaly / 3.0)]

Combines machine learning probability with statistical Kalman residual bounds to prevent single-model false positives.

Volumetric DoS / DDoS Rules

  • DoS: Single source IP → Destination with >= 1,000 packets & >= 1,000 pps.
  • DDoS: >= 3 distinct source IPs → Destination with >= 1,000 packets & >= 1,000 pps.
