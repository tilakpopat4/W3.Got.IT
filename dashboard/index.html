How to use the detector

Generic flow model

Broad benign-versus-malicious flow model for general traffic. It is not a dedicated DDoS labeler.

Mythic HTTP C2 model

Specialized for TQH Mythic Poseidon HTTP command-and-control patterns. Do not use it as a general website verdict.

Live interface

Scapy reads packets from the selected Npcap interface, updates flows in memory, and refreshes this report every second. It never sends or blocks packets.

How a flow becomes flagged

A flag is a review signal, not proof that an attack occurred.

  1. Feature extraction: packet metadata is converted to flow features such as packet count, bytes, rate, timing, TCP flags, and packet-size statistics.
  2. Classifier score: XGBoost returns a malicious probability from 0 to 1. The flow is flagged when probability >= threshold.
  3. Kalman score: the filter compares rate, inter-arrival time, and SYN count with expected behavior and reports an anomaly score/level.
  4. Fused confidence: 0.7 × classifier probability + 0.3 × bounded Kalman anomaly.
  5. Severity: a possible volumetric event can raise severity; otherwise a flagged flow is normally medium severity.
  6. DoS/DDoS: this requires destination aggregation. Current conservative rule: at least 1,000 packets and 1,000 packets/sec; DDoS additionally needs at least 3 distinct sources.
